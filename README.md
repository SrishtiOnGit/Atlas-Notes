## Atlas Notes

A digital travel experience that lets you explore the world through interactive postcards, daily discoveries, and cultural snapshots.

Atlas Notes is a travel-inspired web application that helps users discover beautiful destinations across the world through immersive digital postcards. Each interaction feels like receiving a postcard from a new corner of the planet — complete with visuals, weather insights, and cultural context.

 ## Key Features
 Daily Postcard

Wake up to a new destination every day — handpicked from around the world, styled like a real travel postcard.

Random Discovery

Feeling adventurous? Instantly explore random destinations and let the world surprise you.

 Weather Insights

Get real-time weather context for each location to understand its environment better.

 Interactive Maps

Visualize destinations geographically and explore where each postcard belongs.

 Local Phrases

Learn simple greetings and phrases from different cultures around the world.

 Save Favorites

Build your personal collection of favorite destinations and revisit them anytime.

## What This Project Demonstrates
